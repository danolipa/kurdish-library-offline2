# Open-source book-summary imports

## Sources
- Books for Agents — https://github.com/danpalmieri/books-for-agents — content CC BY-SA 4.0.
- AustinT/book-summaries — https://github.com/AustinT/book-summaries — repository marked MIT.

## Import
Run npm run sources:import then npm run sources:merge.
Original English material is stored in textOriginal; Kurdish adaptation is stored separately in textKu so provenance remains auditable.

Public GitHub visibility alone is not permission to redistribute. Sources without a clear reuse license are excluded.
Adapted CC BY-SA content must retain attribution and compatible ShareAlike terms.
