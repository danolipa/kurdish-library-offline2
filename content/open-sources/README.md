# Open-source book-summary imports

## Sources
- Books for Agents — https://github.com/danpalmieri/books-for-agents — content CC BY-SA 4.0.
- AustinT/book-summaries — https://github.com/AustinT/book-summaries — repository marked MIT.

## Import
Run npm run sources:import then npm run sources:merge.
Original English material is stored in textOriginal; Kurdish adaptation is stored separately in textKu so provenance remains auditable.

Public GitHub visibility alone is not permission to redistribute. Sources without a clear reuse license are excluded.
Adapted CC BY-SA content must retain attribution and compatible ShareAlike terms.


## Verified summary datasets

- **Books for Agents** — book content is stated by the project as CC BY-SA 4.0; summaries are described as original analyses. We import with attribution/provenance. See source URL in each record.
- **AustinT/book-summaries** — repository is MIT-licensed and contains the author's book summaries; imported records retain the repository URL and license notice.
- **CMU Book Summary Dataset** — 16,559 plot summaries extracted from Wikipedia, released under Creative Commons Attribution-ShareAlike; the pipeline keeps the dataset attribution and separately tracks the underlying work. 

Copyrighted source summaries without an explicit compatible license are not copied merely because their GitHub repository is public.
