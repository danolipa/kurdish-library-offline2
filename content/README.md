# Kurdish Library content packs

Put lawful, distributable content in this directory before running:

npm run content:index

Files:
- summaries.json
- quotes.json
- authors.json

Each record may include source/sourceUrl and rights. Use public-domain, licensed, user-provided, or original material. Do not bulk-copy proprietary quote/summarization databases.

The generated files are written to src/data/ and can be bundled into the offline app.
